# 快速使用手册

**版本**：v1.1.1 · **入口**：`python main_app.py` · 窗口标题：**系统集成测试数据解析**

## 三步完成转换

1. **选择 ASC**：在「数据转换」页选择单个 ASC，或切换到「多文件拼接模式」添加多个 ASC。
2. **添加 DBC**：添加与日志匹配的一个或多个 `.dbc` 文件。
3. **开始转换**：选择输出目录，设置采样间隔（默认 0.1 秒），点击「开始转换」。

完成后在输出目录查看 `Summary.csv`、各 `BATP*.csv` 及 `Others.csv`。

## 四个标签页

| 标签 | 用途 |
|------|------|
| 数据转换 | ASC → CSV |
| 数据可视化 | 单文件曲线 |
| 数据对比 | 多文件叠加对比 |
| 数据导出 | 从 CSV 挑选列另存 |

## 可视化要点

- **缩放**：滑块或鼠标滚轮
- **平移**：滚动滑块或按住左键拖动
- **十字线**：勾选「十字参考线」
- **找列**：使用「列搜索」过滤

## 对比说明

勾选 2～5 个 CSV 与若干数据列后点击「生成对比图」。**当前版本不支持**将对比图导出为 PNG/PDF，请使用系统截图。

## 输出文件

| 文件 | 含义 |
|------|------|
| `Summary.csv` | 统计汇总 |
| `BATP3.csv` 等 | BatP 分组（文件名大写） |
| `Others.csv` | 其余信号 |

## 常见问题

| 现象 | 处理 |
|------|------|
| 转换慢 / 内存不足 | 增大采样间隔（如 0.5～1.0 s） |
| 信号偏少 | 补全 DBC；开「调试模式」看日志 |
| 图表中文乱码 | Windows：安装微软雅黑/黑体；Linux：安装 CJK 字体 |
| Excel 乱码 | 使用 `utf-8-sig` 编码导出 |
